# Happy New Year 2026 🎆

Hey! This is a cool 3D animation I made to celebrate the New Year 2026. It's built using Three.js and runs right in your browser.

## What's inside?

- A snowy night scene with a glowing moon 🌙
- A forest of 3D Christmas trees 🎄
- Fireworks exploding in the sky 🎇
- A magical golden swirl effect ✨
- "Happy New Year 2026" written in glowing particles

## How to run it

1. Clone or download this folder.
2. Since it uses ES modules, you need to run it on a local server (opening `index.html` directly might give CORS errors).
   - If you have VS Code, just use the **Live Server** extension.
   - Or run `python3 -m http.server` in the terminal and open `localhost:8000`.

## Tech Stack

- HTML/CSS
- JavaScript
- [Three.js](https://threejs.org/) (for all the 3D magic)

Enjoy the view and have a great year! 🚀
